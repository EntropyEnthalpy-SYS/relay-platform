- 域名目标会由客户端解析，只选择公网地址；需要本机目标时使用 `--udp-socks5-allow-private`。
- 固定 `--udp-target` 是显式配置，不受该过滤影响。
- 新增默认拒绝私有目标的回归；既有双目标测试显式允许本机目标。

## 0.108.0 本轮进展

- SOCKS5 UDP 增加可重复 `--udp-allow-cidr`，只允许指定 CIDR 内的目标。
- 域名先解析再做 CIDR 与公网策略检查；空 allowlist 表示不额外限制。
- 固定 `--udp-target` 仍不受该策略影响。
- 新增 allowlist 拒绝未列出目标的回归。

## 0.109.0 本轮进展

- 增加 `--udp-queue`（默认 1024，16..65536）控制 UDP 接收队列。
- 增加 `--udp-rate-pps`（默认 0 不限）限制每 association 双向包速率。
- 超速数据报丢弃并计入 `relay_reverse_mux_udp_rate_limited_total`。
- 队列满仍计入 `relay_reverse_mux_udp_dropped_total`。

## 0.110.0 本轮进展

- 新增独立 `relay http2-connect` 命令，提供 h2c（HTTP/2 prior knowledge）CONNECT 正向代理。
- 支持 Basic `Proxy-Authorization`、私有目标开关、10 秒握手/连接超时。
- 使用 hyper/h2 驱动 HTTP/2 流，CONNECT 成功后通过 upgrade 做双向字节隧道。
- 测试覆盖私有目标 echo 和 Basic 认证 407/200。
- 限制：这是独立监听器，尚未接入规则引擎的计量、ACL、限速、规则模板和 UI；不支持 HTTP/2 over TLS/ALPN。

## 0.111.0 本轮进展

- `relay http2-connect` 增加 `--tls-cert/--tls-key/--tls-client-ca`，提供 HTTP/2 over TLS（ALPN h2）。
- 可选客户端证书复用公网 TLS 的 mTLS 思路。
- TLS 握手 10 秒超时，CONNECT 目标连接 10 秒超时。
- 新增 TLS h2 CONNECT 真实 h2 客户端 echo 回归。
- 限制：独立命令，尚未接入规则引擎计量/ACL/限速/UI。

## 0.112.0 本轮进展

- 修复 R111-01：HTTP/2 握手期限仅覆盖连接前言与初始 SETTINGS，已建立隧道不再受 10 秒总时长限制；CONNECT 的 DNS 与拨号共享独立期限。
- 修复 R111-02：mux UDP 使用有界独立工作任务，DNS、设置与发送不再堵塞共享读循环；取消会清理排队数据。
- 修复 R111-03：SOCKS5 模式只接收已允许目的 IP/端口的回复，并限制条目数量及有效期。
- 修复 R111-04：失败、关闭和重置直接释放 UDP 对应的流名额，队列拥塞不丢失生命周期事件。
- 保留四项独立审查回归，并增加 HTTP/2 长连接/多流/半关闭、握手边界、UDP 队列/取消/失败回收测试。
- 完整验收记录见 0.112.0 verification 包。仍为开发版本，Linux/WAN 和完整产品验收继续保留为待办。

0.112.0 本机验证：426 项 Rust、29 项 Python、2 组 JavaScript 断言通过；四项原始验收探针独立重跑通过；优化构建与 8 组 release CLI 回归通过。Linux/WAN 验收仍待进行。
