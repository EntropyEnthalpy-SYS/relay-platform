# 工单

0.29.0 增加租户范围内的支持工单与消息线程，补齐运营模块的工单子项。

## 模型

```json
{"subject":"无法连接","body":"节点没有响应","priority":"high"}
```

- 优先级：`low`、`normal`、`high`；状态：`open`（待处理）、`pending`（处理中）、`closed`（已关闭）。
- 主题 1..200 字节；消息 1..10,000 字节。
- 工单属于创建者的租户，不可跨租户移动。
- 消息分公开回复和管理员内部备注；内部备注只对系统管理员/同租户管理员可见，工单所有者永远看不到。

## 权限与状态

- 普通用户只能查看/回复自己的工单，可关闭自己的工单；不能设置处理中。
- 租户管理员查看本租户工单，可回复、内部备注、设置任意状态；不能访问其他租户。
- 系统管理员查看全部工单。
- 关闭的工单拒绝新消息；管理员可以重新打开。普通用户公开回复会把 `pending` 恢复为 `open`。
- 消息、状态和审计在同一 SQLite 事务中提交；记录在 metadata，schema v5/恢复日志格式 4 不变。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/tickets` | 列表（按角色作用域）/创建 |
| GET | `/tickets/{id}` | 工单和可见消息 |
| POST | `/tickets/{id}/messages` | `{body,internal}`；内部备注仅管理员 |
| PUT | `/tickets/{id}/status` | `{status:"open"|"pending"|"closed"}` |

`/tickets/*` 仅接受登录会话，API 令牌访问 403。面板“工单”页支持新建、查看线程、公开/内部回复、关闭和重新打开（管理员）。

## 验证与限制

- Store 测试覆盖所有者/其他用户/租户管理员/其他租户/系统管理员可见性、内部备注不泄漏、普通用户内部备注 403、关闭权限、关闭后回复 409、管理员重开。
- HTTP 测试覆盖创建、其他用户 403、管理员内部备注、所有者只看到公开消息、关闭和关闭后回复 409。
- 未实现附件、富文本、邮件/推送通知、SLA/自动升级、工单分类/标签、满意度、合并、删除/归档、全文检索和浏览器点击验收。完整运营交易仍未完成。
