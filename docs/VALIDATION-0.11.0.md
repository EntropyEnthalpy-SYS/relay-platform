# 本地验证记录

0.11.0 开发版通过 **161 项自动化测试**、Rust 格式检查、Clippy（警告视为错误）、JavaScript/Python 语法检查及 Release 构建。完整用例、计数和日志见 [validation-evidence.json](validation-evidence-0.11.0.json)、[verification-0.11.0.txt](verification-0.11.0.txt)。完整 22 个模块和实机验收仍未完成，目标继续进行。

## 本轮变更及直接证据

修复补额已经提交、业务尚未开始等待时错过唤醒的竞态。业务现在先构造等待对象，再请求计量；多个等待者都能收到期间的提交通知。新增测试在旧实现上先失败，原始记录见 [0.10.0 回归失败证据](regression-refill-wakeup-0.10.0.txt)，再在新实现上通过。它证明竞态修复，不代表其他补额等待已经消失。

Agent 将同一回复的用量确认与额度更新合为一次事务。新增非法后续授信、真实 SQL 写失败两个测试，要求之前的用量确认和授信一起回滚；正确重试精确消费 128 字节，两次重放回复没有增加可用额度。预留粒度、补额阈值、累计计量与恢复日志屏障保持原约定。

节点新增计量批次、额度等待与超时统计；控制器新增排队、数据库处理及请求总耗时。既有两 Agent 测试验证 API 能看到真实等待、耗尽超时和有序停止后的零等待；控制器统计继续校验未登录/非管理员拒绝。口径和界面入口见 [DIAGNOSTICS.md](DIAGNOSTICS.md)。没有把复合存储耗时称为纯磁盘耗时，也没有把累计诊断当作业务账本。

## 共享额度的相邻版本比较

环境：macOS 27.0.1、arm64、Apple M1 Pro、10 逻辑 CPU、32 GiB，Rust/Cargo 1.99.1、Python 3.14.4。编译结束后按**新版 → 旧版 → 新版**顺序运行，未与其他验证脚本并发。

每连接 32 MiB，两个受管 Agent，每种连接数 5 轮，普通/共享额度组交替，4 MiB 预留，控制器日志开启，最多合并 16 项、等待窗口 2 ms。好吞吐使用单向应用字节除以完整往返验证耗时，不将双向字节翻倍计算。

| 运行 | 总连接数 | 无全局额度 / Mbps | 共享额度 / Mbps |
| --- | ---: | ---: | ---: |
| [0.11.0 前测](benchmark-budget-0.11.0-before.json) | 2 | 4976.2 | 518.0 |
| [0.11.0 前测](benchmark-budget-0.11.0-before.json) | 8 | 9618.1 | 1331.7 |
| [0.10.0 对照](benchmark-budget-0.10.0-recheck.json) | 2 | 4815.3 | 390.6 |
| [0.10.0 对照](benchmark-budget-0.10.0-recheck.json) | 8 | 10068.6 | 1317.0 |
| [0.11.0 后测](benchmark-budget-0.11.0-after.json) | 2 | 4546.3 | 695.5 |
| [0.11.0 后测](benchmark-budget-0.11.0-after.json) | 8 | 9787.1 | 1305.0 |

每次运行的节点和控制器业务账本均为 **6,719,275,008 字节**，预算消费 **3,359,637,504 字节**，停止后未使用预留均为零。[当前基线](benchmark-budget-0.11.0.json)保留第一轮新版原始结果，不挑选较快的后测覆盖它。旧版二进制 SHA256 为 `45d52994fa0332ab2dc74d38360447f885b9e7592552e491c4e89bb6e8ab2d8a`。

两连接的新样本较相邻旧版高，但两次新版之间也有显著波动；八连接结果在相近量级。本实验没有单独分离唤醒修复、事务合并、诊断开销和系统负载，不能据此宣称固定提升比例或最终性能达标。

新增统计帮助定位下一步工作。第一轮新版的控制器队列平均 7.18 ms，数据库批次平均 21.37 ms，请求处理平均 28.25 ms。它们是**整个进程生命周期**的计数，包含准备和结束阶段，不是只截取吞吐测量窗口；数据库批次还包含线程池和锁等待，不能把全部时间归因于 fsync。

本轮 1033 个同步请求形成 626 个提交批次，实测最大合并 4 项；没有拥塞退回或提交失败。新版两次测量的各节点均报告零计量失败、零额度超时，结束时正在等待数为零。额度等待总时间可因并发相加超过实际运行时间，不应当作停机时长。

## 剩余发布门槛

- 两台 Linux 实机、实际网卡/路由与 Linux UDP packet-info；用户已有服务器，系统、架构与节点数待补充。
- 浏览器视觉与点击验收：此前本机地址权限检查拒绝，未绕过；本轮只做源码与语法检查。
- 真实 WAN、同条件竞品对照、万级/十万级连接和 72 小时混合负载。
- 异常预留回收、分布式身份互斥、全局公平限速、日志异地存储/轮换、密钥迁移和完整灾难恢复。
- [完整 22 模块](REQUIREMENTS.md)中的聚合、组网、运营交易、订阅、共享与其他未完成项；详细状态见 [STATUS.md](STATUS.md)。

schema v4 和恢复日志格式不变。先升级控制器再升级 Agent，因为新节点会发送计量诊断字段；旧控制器严格拒绝未知字段。包声明 Rust 1.89，实际验证为 1.99.1。此版本不是全功能最终版。
