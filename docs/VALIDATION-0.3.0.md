网络验收使用本机真实套接字和临时 SQLite 数据库。故障注入包含控制器停止/异常响应、端口占用、数据库事务失败、旧备份与响应重放。新增跨节点额度测试在总额度 98,304 字节下完成两路 TCP 往返并精确耗尽；另测 128 字节 UDP 总额在控制器中断时仅消费已预留的 64 字节，以及 64 字节批次完整承载 4 KiB UDP 包。

完整回归曾暴露 TLS 测试材料的偶发解析失败。检查本机 LibreSSL 3.3.6 随机生成的 1024 个测试 EC 密钥，其中 1 个 SEC1 私有标量编码为 31 字节；原测试材料可能触发 ring 对固定长度编码的拒绝。测试改为 ring 生成标准 P-256 PKCS#8，再由 OpenSSL 签发证书；未放宽运行时私钥或证书验证。修复后的全部测试通过。

CLI 另行启动回显目标与 Release 转发进程，探测 TCP/UDP 后核对 176 个接纳字节，并验证在线备份账本一致。记录见 [cli-smoke.json](cli-smoke-0.3.0.json)。验证子进程均已停止。

## 无全局额度的回环基准

环境为 macOS arm64、Apple M1 Pro、10 个逻辑 CPU、32 GiB 内存、Rust/Cargo 1.99.1。无 TLS，使用同一 Python 回显目标；预热后直连/转发交替，每连接 32 MiB，5 轮取中位数。吞吐按单方向应用字节计算，账本同时计入上下行。原始记录见 [benchmark-local.json](benchmark-local-0.3.0.json)，内含所测二进制 SHA-256。

| 并发 TCP 连接 | 直连中位数 / Mbps | 转发中位数 / Mbps | 转发 / 直连 |
| --- | ---: | ---: | ---: |
| 1 | 14511.1 | 5289.0 | 36.4% |
| 4 | 15852.5 | 11264.8 | 71.1% |

UDP 每次 1200 字节、100 次回显、0 次失败；直连 RTT 中位数 40.6 μs，转发 163.1 μs，转发 P95 182.2 μs。全部转发接纳量与账本均为 **1,680,058,752 bytes**。

## 两个 Agent 的共享额度基准

启动一个临时控制器、两组各两个 Agent：一组不设置全局额度，一组共享同一个用户额度；两组均执行本地持久化接纳。按组交替传输，每连接 32 MiB、3 轮，报告为两个节点合计单方向有效吞吐。非被测组仅保留控制心跳，不传输业务载荷。均为本机回环、无 TLS，不是两台服务器或广域网。

| 预留批次 | 两节点总连接数 | 无全局额度 / Mbps | 开启额度 / Mbps | 开启 / 未开启 |
| --- | ---: | ---: | ---: | ---: |
| 4 MiB | 2 | 6022.4 | 3802.0 | 63.1% |
| 4 MiB | 8 | 10850.3 | 9001.3 | 83.0% |
| 32 MiB | 2 | 6124.7 | 4348.1 | 71.0% |
| 32 MiB | 8 | 10930.8 | 10919.2 | 99.9% |

原始数据见 [4 MiB 批次](benchmark-budget-0.3.0.json) 与 [32 MiB 批次](benchmark-budget-32m-0.3.0.json)。每次完整基准的 Agent 与控制器规则账本均为 **4,034,920,448 bytes**；其中预算组消费 **2,017,460,224 bytes**，正常停止后 `committed_bytes` 与已消费量相等，未用预留为 0。所有 TCP 载荷逐字节验证。

正常补额的合并等待已缩短为 2 ms，额度不足和控制请求失败分别退避。较大预留能减少控制交互，但也会增加节点失联后的保守占额。当前单连接仍有显著计量开销；报告未隔离 Python、内核和磁盘成本，也未测慢控制链路或公平性。单次接近无预算吞吐不代表零开销，更不代表性能优于参考产品。

历史 0.1.0/0.2.0 报告分别保存在 `benchmark-local-0.1.0.json`、`benchmark-local-0.2.0.json` 与对应证据文件；初次短样本保留在 `benchmark-local-initial.json`。不同时间采样未隔离系统负载，不作严格跨版本性能结论。

## 验收边界

- 管理界面源码和 API 已实现，浏览器权限检查拒绝了本机地址访问；视觉、点击和移动端布局尚未验收，没有绕过限制。
- Linux systemd 模板未实机部署；无两台 Linux 节点、真实广域网、同条件 Realm 基线、万级连接或 72 小时混合负载结果。
- TLS 功能通过不等于 TLS 压力通过。macOS UDP 功能测试覆盖最大 8192 字节，Linux 60000 字节分支尚未运行。
- 未执行独立断电/文件系统持久化实机试验；测试覆盖事务故障、正常重启、旧快照和确认语义。
- 用户/租户/节点总流量额度通过本地验收；全局速率、公平分配、周期调度、端口组/共享资源预算、异常预留恢复未完成。
- 控制器备份恢复后暂停新预算分配，目前没有解除隔离的恢复 API。跨机器身份互斥、旧配置/身份恢复、密钥迁移、原始文件系统快照及两端都丢失的未上报数据仍不能自动处理。
- 完整 22 模块与最终发布门槛仍以 [STATUS.md](STATUS.md) 和 [REQUIREMENTS.md](REQUIREMENTS.md) 为准，目标未完成。
