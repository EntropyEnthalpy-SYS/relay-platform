# 本地验证记录

0.4.0 开发版本通过 **68 项自动化测试**、Rust 格式检查、Clippy（警告视为错误）、浏览器脚本与 Python 脚本语法检查，Release 构建成功。源码指纹、二进制校验值和逐项测试见 [validation-evidence.json](validation-evidence-0.4.0.json)，检查输出见 [verification-0.4.0.txt](verification-0.4.0.txt)。

**恢复功能通过本地验证，但新增严格日志同步导致明显性能回退。此版仍是开发检查点，不是最终性能版本。** 完整 22 模块继续保留，不能据测试数量认定全功能完成。

## Release CLI 恢复演练

[recovery-smoke.json](recovery-smoke-0.4.0.json) 记录真实控制器与 Agent 子进程：先生成备份，再创建节点、注册身份、发布规则并转发；停止控制器后，Agent 用已有预留继续传输；由 CLI 重放旧备份并启动新控制器，同一 TCP 连接继续传输并获取新额度。

本次从事务 4 恢复到 11，重放 7 个事务。Agent、恢复后的控制器、预算已消费与停止后已承诺额度均为 **286,720 字节**，未用预留全部归还。旧 API 会话和节点配置恢复；原备份和日志未改变；子进程均正常退出。

另行启动独立转发程序验证 TCP/UDP，账本接纳量为 **176 字节**，在线备份账本一致，见 [cli-smoke.json](cli-smoke-0.4.0.json)。

## 两个 Agent 的共享额度基准与性能回退

一个临时控制器，两个无全局额度 Agent、两个共享用户额度 Agent；两组均采用本地持久化接纳，控制器启用严格恢复日志。组间交替、每连接 32 MiB、3 轮，非被测组只有心跳。报告为两节点合计单方向吞吐，仍是同一台机器上的回环。

| 预留批次 | 总连接数 | 无全局额度 / Mbps | 开启额度 / Mbps | 开启 / 未开启 |
| --- | ---: | ---: | ---: | ---: |
| 4 MiB | 2 | 4884.9 | 306.0 | 6.3% |
| 4 MiB | 8 | 9373.0 | 322.8 | 3.4% |
| 32 MiB | 2 | 5800.7 | 1973.8 | 34.0% |
| 32 MiB | 8 | 10020.1 | 2968.6 | 29.6% |

原始数据见 [4 MiB 批次](benchmark-budget-0.4.0.json) 与 [32 MiB 批次](benchmark-budget-32m-0.4.0.json)。每次完整基准中，Agent 与控制器规则账本均为 **4,034,920,448 字节**，额度组消费 **2,017,460,224 字节**，有序停止后未用预留为 0，载荷逐字节验证。日志状态均正常；4 MiB 测试累计 1044 个日志事务、1,131,701 字节，32 MiB 测试累计 159 个事务、167,358 字节。

小批次需要频繁补额，恢复日志每个事务包含多次同步存储屏障。本机额外实验测得准备记录、提交记录、清单文件与清单目录的 F_FULLFSYNC 中位耗时分别约 4.04、4.10、4.99 和 4.64 ms。Rust 的 Apple 平台 `sync_all` 使用 F_FULLFSYNC，可核查 [标准库实现](https://doc.rust-lang.org/src/std/sys/fs/unix.rs.html#1264-1285)。据此推断同步写盘是主要瓶颈；尚未完成逐事务全链路性能剖析。没有通过跳过同步来改善数字。

0.3.0 同类 4 MiB/8 连接样本约 9.00 Gbps，本次为 0.32 Gbps，回退显著；不同时间负载未隔离，不能当作严格版本 A/B。32 MiB 批次减少交互但增加失联占额，也没有消除开销。下一步优先研究合并提交和补额调度，保留“确认后可恢复”的合同。尚无同条件 Realm 或另两个产品基准，不作性能领先声明。

## 验收边界

- 管理页面源码和 API 已有实现；本机浏览器访问未获授权，视觉、点击和移动端布局未验收。
- 无 Linux 实机部署、两台真实节点、广域网、同条件产品基线、万级连接或 72 小时混合负载。
- TLS 功能通过不等于 TLS 压力通过。macOS UDP 覆盖最大 8192 字节，Linux 60000 字节分支尚未运行。
- 未执行实机断电、文件系统损坏、整盘丢失和异地恢复；日志与最新清单必须完整保留，不能证明同时回退文件的新鲜度。
- 异常节点未知预留、分布式身份租约、周期调度、全局速率、公平分配、密钥迁移、日志轮换和异地复制未完成。
- 控制器恢复会重建日志中已有的身份和配置，不能重建节点磁盘上已经丢失且未上报的数据。完整灾难恢复与其余模块继续见 [STATUS.md](STATUS.md) 和 [REQUIREMENTS.md](REQUIREMENTS.md)。

历史 0.3.0 记录保留在 `VALIDATION-0.3.0.md` 及带 `-0.3.0` 后缀的 JSON；0.1.0/0.2.0 证据也保留。旧版报告中的相对链接应结合对应版本文件或源码包阅读。
