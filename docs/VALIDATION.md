# 本地验证记录

当前开发版本通过 28 项自动化测试、Rust 格式检查、Clippy（警告视为错误）、浏览器脚本语法检查与 Python 脚本语法检查。Release 构建成功。证据摘要见 [validation-evidence.json](validation-evidence.json)，完整测试代码位于 `crates/relay-platform/tests/`。

## 真实验证范围

| 组 | 通过数 | 验证内容 |
| --- | --- | --- |
| 控制与 Agent | 4 | HTTP 身份与角色；HTTPS 地址限制；注册响应丢失重试；控制器离线、无效响应、Agent 重启与恢复补报 |
| 转发引擎 | 16 | TCP 二进制与半关闭；UDP 数据报/空包/来源隔离；IPv4/IPv6及双协议；配置冲突保留旧监听；目标分配；会话与配额并发；限速；ACL；数据库事务故障；限速中的 UDP 监听迁移释放旧端口 |
| 账本与模型 | 8 | 周期与重启；累计重放；禁止倒退；租户权限；会话撤销；注册单次绑定；版本冲突；备份恢复；非法配置拒绝 |

这些测试使用本机真实套接字和临时 SQLite 数据库，不把模拟连接成功作为转发验收。故障注入包括端口占用、控制器停止/异常响应和数据库事务失败。

CLI 另行启动了回显目标与 Release 转发进程，探测 TCP/UDP 后核对 176 个接纳字节，并验证在线备份恢复的账本一致。证据见 [cli-smoke.json](cli-smoke.json)。所有验证用服务已停止。

## 回环性能烟测

- 环境：`macOS-27.0.1-arm64-arm-64bit-Mach-O`，架构 `arm64`，`rustc 1.99.1 (58cf8f9c3 2026-10-13)`。CPU 具体型号未获取；当前执行权限拒绝了 sysctl 查询。
- 条件：同一 Python 回显目标，无 TLS；先预热，直连/转发交替，每连接 32 MiB，5 轮取中位数。有效吞吐按单方向应用字节计算，账本同时计入上下行。
- 原始记录：[benchmark-local.json](benchmark-local.json)。报告中固定了所测二进制 SHA-256。

| 并发 TCP 连接 | 直连中位数 / Mbps | 转发中位数 / Mbps | 转发 / 直连 |
| --- | ---: | ---: | ---: |
| 1 | 14713.9 | 4624.5 | 31.4% |
| 4 | 15599.8 | 11409.8 | 73.1% |

UDP 每次 1,200 字节，100 次回显，记录失败数为 0；直连 RTT 中位数 40.2 μs，转发 163.3 μs，转发 P95 为 181.0 μs。

本次所有经过转发的应用接纳字节预期值与持久化账本均为 **1,680,058,752 bytes**，完全一致。

当前单连接仍有显著额外开销，持久化计量路径是后续优化对象。该烟测没有隔离 Python 目标、内核回环和磁盘的各项成本，不能将观察到的差异全部归因于某一个函数；也没有运行 Realm 基线，因此不能声称性能领先原项目。

初次短样本另保留在 `benchmark-local-initial.json`。它与当前报告的二进制及载荷不同，不构成严格的优化前后对照。

## 验收边界

- 浏览器权限检查拒绝了打开本机管理地址，原因是地址访问未获用户授权。没有改用其他浏览器或绕过授权。管理界面的视觉、点击流程和移动端布局尚未验收。
- Linux 的 systemd 模板尚未部署；没有两台 Linux 节点、广域网、万级连接、长时间混合负载或聚合测试。
- macOS UDP 验收覆盖最大 8,192 字节的数据报；测试源代码中 Linux 的 60,000 字节分支尚未运行。
- 未做独立的断电/文件系统持久化实机测试；当前检验了事务失败、重启与确认语义。
- 旧备份回滚后的权威账本水位对账、全局用户预算和完整数据迁移仍未完成。
- 完整 22 模块及最终发布门槛见 [STATUS.md](STATUS.md) 和 [REQUIREMENTS.md](REQUIREMENTS.md)。
