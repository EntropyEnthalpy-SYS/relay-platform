# 本地验证记录

0.13.0 开发版通过 **187 项自动化测试**、Rust 格式检查、Clippy（警告视为错误）、JavaScript/Python 语法检查及 Release 构建。完整用例见 [validation-evidence.json](validation-evidence.json)，构建和测试日志见 [verification-0.13.0.txt](verification-0.13.0.txt)。本轮增加严格节点执行租约；完整 22 模块与 Linux 实机验收仍在进行中。

## 节点执行租约与直接证据

新增 11 项自动化测试：5 项控制器租约存储测试、1 项 Agent 有效期测试、5 项真实 HTTP/节点集成测试。覆盖并发领取、丢失回复的幂等申请、续租、过期、旧证明拒绝、批量同步隔离、预算运行绑定、事务回滚、日志恢复、旧备份等待、复制状态交接、正文卡住、严格离线重启和异常取消。

独立 [Release 租约验收](node-leases-smoke.json)运行一个控制器、三个先后接入的 Agent 进程、TCP/UDP 回显与共享用户额度：

- 运行期间复制节点数据库，原实例持续续租。复制实例等待 6.15 秒，超过本次 5 秒 TTL，仍不抢占监听、不改变原预算运行编号。
- 原实例结算并释放后，复制实例取得第二代所有权，约 0.46 秒完成接替。节点、控制器和预算消费均为 **30,912 字节**，已承诺额度与消费相同，未使用预留为零。
- 再次启动取得第三代所有权，确认全部业务用量后停止控制器。Agent 约 **4.34 秒**后以租约丢失退出，已有 TCP、TCP 监听和 UDP 转发均停止。结束后本地及控制器数据库均为 **35,368 字节**。
- 停控制器前还保留 3,736 字节预留余额；本次不声称失联结算或退款完成。租约到期不会自动释放未知消费对应的额度。

正常释放必须在引擎停止和结算完成后发生。异常取消测试曾在旧实现复现活动 TCP 连接残留，加入引擎 Drop 取消逻辑后通过；[失败候选记录](regression-agent-abort-before-fix-0.13.0.txt)保留，属于本轮未完成候选。当前完整 187 项验证均通过。

执行模式、时钟假设、冷启动等待、升级和单控制器限制见 [NODE_LEASES.md](NODE_LEASES.md)。新 HTTP 节点默认严格 30 秒，已有节点和显式离线节点保留原策略。测试没有证明恶意 Agent、任意系统冻结或多控制器能被隔离。

## 本机性能回归

环境为 macOS 27.0.1、arm64、Apple M1 Pro、10 逻辑 CPU、32 GiB；Rust/Cargo 1.99.1、Python 3.14.4。编译、完整测试结束后顺序运行基准，各性能脚本没有相互并发。最低声明 Rust 1.89 尚未验收。没有做同条件竞品或版本间因果对照。

[独立转发](benchmark-local.json)：无 TLS，每连接 32 MiB、5 轮；账本 1,680,058,752 字节一致。

| --- | ---: | ---: |
| 1 | 10924.1 | 4489.6 |
| 4 | 12055.7 | 10661.3 |

UDP 每包 1,200 字节、100 次、零失败；转发 RTT 中位 179.2 μs，P95 282.8 μs。

[两 Agent 共享额度](benchmark-budget.json)：严格节点、每连接 32 MiB、5 轮、4 MiB 预留，恢复日志开启，最多合并 16 项、等待 2 ms。

## 单连接多路径回归

[聚合原始结果](benchmark-multipath.json)使用实际控制器、两 Agent、mTLS 和两个 Python 限速代理。路径每方向配置 2 MiB/s 与 1 MiB/s；每轮一个应用连接传输 4 MiB、测量三轮，轮换模式。好吞吐为单向已校验应用字节除以完整往返耗时。

| 模式 | 中位好吞吐 / Mbps |
| --- | ---: |
| 单快路径 | 14.27 |
| 双路径分片 | 21.80 |
| 双路径复制 | 10.13 |

本次分片与单快路径比为 **1.527**，约提高 52.7%，达到脚本预设的超过 15% 观察阈值。业务中切断快子流后，同一应用连接的全部内容校验通过。六条规则账本合计 170,917,888 字节一致；额外复制与重传开销保留在原始报告，结束后活跃会话及子流归零。

该结果仅代表软件限速回环。Python 定时/调度、同机资源与路径配置影响结果；不能推定真实 WAN 增益、独立物理路由、最大吞吐或比其他产品更快。上一版原始记录保存在 [0.12.0 验证](VALIDATION-0.12.0.md)。
