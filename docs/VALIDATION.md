# 本地验证记录

0.17.0 开发版通过 **234 项自动化测试**、Rust 格式检查、Clippy（警告视为错误）、JavaScript/Python 语法检查与 Release 构建。完整用例见 [validation-evidence.json](validation-evidence.json)，日志见 [verification-0.17.0.txt](verification-0.17.0.txt)。本轮接入单节点身份撤销、限时替换注册与旧配额周期保护；完整 22 模块、Linux 实机与浏览器验收仍在推进。

## 节点身份撤销与替换

新增 **13 项测试**：9 项存储/事务测试和 4 项 HTTP/真实 Agent 测试。覆盖权限、并发撤销/轮换、操作幂等、过期/重签、严格窗口、历史规则配额保护、离线实例外部停止确认、注册响应丢失、旧状态拒绝和事务失败回滚。测试同时修复了回显夹具仅保留 TCP 端口、随后绑定 UDP 可能撞到并行客户端的竞争；现在同时持有两种套接字再启动服务。

[独立 CLI 演练](replacement-smoke.json)使用真实控制器与多个前后接替的 Agent、临时隔离代理，以及同一规则的 TCP/UDP：

- 原节点先上报 **320 字节**，隔离控制连接后又实际传输并持久化 **160 字节**。撤销使旧凭据失效；严格节点在已获准窗口结束后退出，观测约 **3.79 秒**，原 TCP 关闭。
- 新实例使用全新私有状态，注册版本为 **3**，等待期间没有预算运行；约 **4.70 秒**取得第 3 代租约。新 TCP/UDP 可用；重试原撤销请求不影响新身份，随后常规轮换到版本 4，租约保持。
- 不支持身份版本的替换注册返回 **426**，不消费票据。1 秒令牌到期后返回 **410**，真实 Agent 退出；重放同一签发操作没有延长期限。重新签发推进至版本 **7**，旧令牌被拒绝，新实例正常接入。
- 从撤销前的旧备份重放 **22 个事务**，身份、历史操作、期限和退役标记一致。3 份退役长期凭据在各 6 个节点接口均被拒绝；4 份旧/已消费注册令牌不能再次注册。重放旧管理操作不改变后来身份。恢复后约 **5.12 秒**取得第 6 代租约，再次完成 TCP/UDP。
- 全程实际观察到 **800 字节**业务；控制器、最新 Agent 已知累计与预算消费均为 **640 字节**，原节点未上报的 **160 字节**仍未被恢复。预算已承诺 **1,344 字节**，其中原节点仍保留 **704 字节**未知预留；没有伪造消费或退款。原节点私有账本仍为 480 字节，转发配置始终为第 1 版。

规则配额保护由另一组实际 HTTP/Agent 集成测试验证：撤销标记全部历史周期，旧配额启用时替换实例等待；显式发布新周期后才接管，旧用量不清零。CLI 报告使用无规则级配额的规则，不将它当作这项保护的证据。离线策略实例需先从外部停止并确认，再替换为严格策略；控制器无法强制关闭非协作主机。字段和升级顺序见 [NODE_IDENTITY.md](NODE_IDENTITY.md)。

页面补齐了旧操作幂等重放后对最新身份/票据状态的显示处理。该修正前的候选验收队列已停止，以下 18 份记录全部来自修正后的最终二进制；没有把候选结果并入最终证据。页面视觉和点击仍未验收。

## 节点凭据轮换回归

继续回归常规换钥的 6 项存储/事务、2 项 Agent 持久化与并发请求、3 项 HTTP/真实 Agent 测试。覆盖权限、版本、严格租约证明、退役密钥拒绝重用、并发唯一胜出、写入失败回滚、丢失回复确认和旧备份重放。

[独立 CLI 验收](credentials-smoke.json)使用真实控制器和 Agent 进程，经临时本机代理注入两种失败。新凭据只在 Agent 私有状态库生成和保存，没有写入报告或源码包。

- 在线轮换保留同一 TCP 连接和第 1 代租约，UDP 正常回复，规则配置始终为第 1 版。另有自动化测试专门延迟携带旧凭据的续租至换钥之后，验证认证重试仍保持运行。
- 控制器提交前、提交后分别 SIGKILL Agent。两个边界都保留本地候选，重启后使用**同一候选**完成，没有重置身份或重复增加凭据版本；包含正常租约接替等待的恢复实测约 4.76 秒和 4.78 秒。
- 停止 Agent 后排队新任务，重新启动后自动处理，最终凭据版本为 **5**。
- 从第一次轮换前的旧控制器备份重放 **36 个事务**，任务、回执和退役记录一致；**4 份旧凭据**均被拒绝。原 Agent 可继续接入并实际转发。
- 最终本地、控制器、预算已消费和已承诺量均为 **992 字节**，没有因轮换重复扣量或留下已知未用预留。所有临时进程退出。

字段、事务边界、升级与恢复方式见 [NODE_CREDENTIALS.md](NODE_CREDENTIALS.md)。常规换钥保留原状态，紧急撤销与全新状态替换按上述独立合同验收；强制停止被控制主机和完整身份生命周期仍未完成。

## 节点资料与生命周期回归

继续回归资料编辑、批量事务、暂停、断联到期和到期延长后的预算恢复。

独立 [Release 进程验收](node-profiles-smoke.json)使用两个节点资料记录、一个实际转发节点，以及先后启动的真实 Agent：

- 类型、分组、标签和备注查询匹配，成本 **12,500,123 百万分之一货币单位**精确保存。已有 TCP 连接在资料修改后继续传输，转发配置始终为第 1 版。
- 旧资料修订被拒绝；批量第二节点冲突时第一节点也不修改。成功保存返回两份节点修订回执。
- 暂停后约 **0.48 秒**退出，已有 TCP、监听和 UDP 均关闭。节点、控制器及预算结算为 **448 字节**，已知未使用预留归还。
- 重新允许并设置到期时间后，先观测到租约已按到期截短，再停止控制器并继续 TCP/UDP。监听关闭观测比到期早 **472 ms**；到期后的原状态重启被 HTTP 410 拒绝。
- 清除到期后，按冷启动保留期等待约 **5.14 秒**，取得第 3 代所有权，并核对原状态预留，补报 **160 字节**。继续业务后，三份账本最终均为 **1,216 字节**，预算已承诺量等于实际消费。
- 从资料修改前的旧控制器备份重放 **25 个事务**，逐字段核对名称、资料修订、成本、分组、暂停/到期设置和转发修订，累计用量仍一致。所有临时进程退出。

API、整数口径、时间假设、离线节点限制和升级步骤见 [NODE_MANAGEMENT.md](NODE_MANAGEMENT.md)。类型和成本仍是管理资料，不自动配置 NAT 或参与选路。暂停按已授窗口收敛；单机测试不证明真实系统冻结、错误系统时钟、跨主机故障或完整身份生命周期已经验收。

## 本机性能回归

环境为 macOS 27.0.1、arm64、Apple M1 Pro、10 逻辑 CPU、32 GiB；Rust/Cargo 1.99.1、Python 3.14.4。编译、完整测试结束后，18 组 Release 验收及基准顺序运行，各性能脚本没有相互并发。最低声明 Rust 1.89 尚未验收。没有做同条件竞品或版本间因果对照。

[独立转发](benchmark-local.json)：无 TLS，每连接 32 MiB、5 轮；账本 1,680,058,752 字节一致。

| --- | ---: | ---: |
| 1 | 13925.0 | 4612.1 |
| 4 | 13935.0 | 11314.6 |

UDP 每包 1,200 字节、100 次、零失败；转发 RTT 中位 175.5 μs，P95 214.3 μs。

[两 Agent 共享额度](benchmark-budget.json)：严格节点、每连接 32 MiB、5 轮、4 MiB 预留，恢复日志开启，最多合并 16 项、等待 2 ms。

## 单连接多路径回归

[聚合原始结果](benchmark-multipath.json)使用实际控制器、两 Agent、mTLS 和两个 Python 限速代理。路径每方向配置 2 MiB/s 与 1 MiB/s；每轮一个应用连接传输 4 MiB、测量三轮，轮换模式。好吞吐为单向已校验应用字节除以完整往返耗时。

| 模式 | 中位好吞吐 / Mbps |
| --- | ---: |
| 单快路径 | 14.00 |
| 双路径分片 | 21.62 |
| 双路径复制 | 10.24 |

本次分片与单快路径比为 **1.544**，约提高 54.4%，达到脚本预设的超过 15% 观察阈值。业务中切断快子流后，同一应用连接全部内容校验通过。六条规则账本合计 170,917,888 字节一致；额外复制与重传开销保留在原始报告，结束后活跃会话及子流归零。

该结果仅代表软件限速回环。Python 定时/调度、同机资源与路径配置影响结果；不能推定真实 WAN 增益、独立物理路由、最大吞吐或比其他产品更快。上一版原始记录保存在 [0.16.0 验证](VALIDATION-0.16.0.md)。
